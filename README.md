# Orchard Catch Game

A full-screen browser game. Slide a basket across a sunny meadow.

## Run

```bash
npm install
npm run dev
```

Then open the local address printed in the terminal.

## Play

Press **Start Game**. Fruit falls from the sky. Each one you catch is worth 10 points. A bomb takes 20 points. A rock takes one of your 3 lives. Every 100 points starts a new level: fruit falls a little faster, and more bombs and rocks appear. It stops getting faster so the round stays playable. Restart puts the difficulty back to the beginning.

Move with the arrow keys or A and D. On a phone or tablet, drag the meadow or hold the side buttons.
