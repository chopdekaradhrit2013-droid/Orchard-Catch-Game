# Orchard Catch Game

A full-screen browser game. Slide a basket across a sunny meadow.

## Run

```bash
npm install
npm run dev
```

Then open the local address printed in the terminal.

## Play

Press **Start Game**. Fruit falls from the sky. Each one you catch is worth 10 points. A bomb takes 20 points. A rock takes one of your 3 lives.

Move with the arrow keys or A and D. On a phone or tablet, drag the meadow or hold the side buttons.
